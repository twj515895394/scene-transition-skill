# QC — 先阻断、后评分

## 1. 硬性审查（必须全部通过）
- [ ] 未改变纪实事实或制造虚假的连续因果
- [ ] 未覆盖原稿；增强版只在要求时输出
- [ ] 前后动作/屏幕方向/人物身份/道具/服装逻辑可解释
- [ ] 所需素材或生成步骤具备可执行性，缺失条件已标明
- [ ] 遵从用户禁忌与安全限制
- [ ] 没有把提示词推测当成成片实测

任一项不合格：状态 BLOCK，必须修改或改选硬切/声音桥接。

## 2. 软评分（100 分）
| 维度 | 分值 | 评分要点 |
|---|---:|---|
| 内容意图与情绪 | 25 | 是否服务人物/故事/主题 |
| 视觉与动作连续 | 25 | 形状、运动、轴线、身份 |
| 音乐与声音 | 15 | 音效/乐句/动态关系 |
| 自然度 | 15 | 是否突兀、是否能隐藏切点 |
| 可实现性 | 10 | 素材/制作要求真实 |
| 创意独特性 | 10 | 有记忆点而非特效堆砌 |

90+ 优秀；80–89 可采用；70–79 待修改；<70 不推荐。
评分必须附证据和修复建议，不能给无理由总分。

## 3. QC 层级
- TEXT_PREVIEW：根据剧本/提示词的“设计预审”，不能宣称已观看实际素材。
- FRAME_REVIEW：依据关键帧审核构图与静态连续性，不能验证动态速度。
- VIDEO_REVIEW：有实拍/成片视频才可审核动态衔接；如未听音频，声音维度仍标待验证。

## 4. 负面场景必测
- 纪录片不同日期素材拼接造成虚假同日连续 → BLOCK
- 无眼部特写却推荐瞳孔穿越 → BLOCK 或 REGENERATE
- 舒缓 Vlog 连续闪帧与甩镜 → 软约束降权
- 已有自然切点，强加 Morph → 推荐保持原切点
- 画面匹配良好但左右手道具突变 → BLOCK，修复后复审
