# Scene Transition Skill

专业影视转场设计与剪辑增强 Skill。为 MV、电影混剪、人物纪录片、第三人称 Vlog、旅行短片、角色展示、叙事电影中的蒙太奇段落等提供 **非破坏式** 转场建议。

## 三项设计决策
1. 输入支持前期（剧本、分镜、视频生成提示词）和后期（成品视频、镜头表、关键帧）。
2. 原稿保持不变；独立输出转场建议，只有明确请求时才输出标记清楚的增强版提示词。
3. 按题材自动选择默认风格，用户指定风格优先；不能为了炫技而转场。

## 使用
把你的分镜、脚本、提示词或视频与任务要求交给 Agent，并要求使用本仓库的 `SKILL.md`。若素材不完整，明确标记未知条件，避免杜撰画面。
输出：镜头分析 → 推荐/不推荐转场 → 可执行方案 → QC。仅文本输入对应设计预审，实际视频验收必须看实际画面。

## 文件
- `SKILL.md`：主流程与触发条件
- `references/scenarios.md`：场景分类与默认风格
- `references/rules.md`：硬约束、软约束、决策门槛
- `references/music.md`：音乐节奏、声音衔接
- `references/ai-video.md`：生成提示词与已成片边界
- `catalog/transitions.md`：40 个技法索引与选择条件
- `references/qc.md`：质检标准
- `templates/plan.md`：输出格式
- `tests/cases.md`：正向与反向用例

## 版本
V1.0：规则与知识库驱动，不依赖脚本、插件、模型特定参数或剪辑软件。维护时逐步丰富案例，并用负例验证“应该不转场”的能力。
