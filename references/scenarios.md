# 场景与风格矩阵

| 场景 | 核心目的 | 优先倾向 | 慎用 |
|---|---|---|---|
| MV / AI MV | 音乐与视觉记忆点 | 节奏硬切、构图/动作匹配、视觉接力 | 每拍都切、无意义闪白 |
| 燃向混剪 / AMV | 高光、强度起伏 | 动作匹配、速度变化、冲击硬切 | 无呼吸段落、连续强闪 |
| 人物纪录片 | 人物真实经历、记忆 | 时间匹配、声音桥接、真实动作连接 | 虚构时空连续、夸张变形 |
| 第三人称人物/情侣 Vlog | 人物存在感、生活氛围 | 动作匹配、门框遮挡、自然硬切 | 没有动机的频繁转场 |
| 旅行 / 城市 | 地点氛围、空间探索 | 运动匹配、地标形状匹配、环境声音 | 虚假的地理连续性 |
| 时尚/角色展示 | 身份、服装、视觉惊喜 | 姿态锁定、轮廓匹配、换装 | 身份失真、服装结构漂移 |
| 电影叙事/音乐段落 | 推动剧情或时间压缩 | 硬切、动作连续、声音桥、时间蒙太奇 | 破坏因果或情绪的炫技 |
| 情绪诗性短片 | 意象、情绪递进 | 色彩/形状/象征匹配、溶解 | 无依据地制造空洞隐喻 |
| 动作/武戏 | 运动连续与接触感 | 动作匹配、冲击切、方向连续 | 轴线跳跃、打击点消失 |
| 产品/品牌 | 质感、识别、卖点 | 细节匹配、材质/形状连续 | 误导真实产品形态 |

## 自动选择原则
优先从内容意图、视听动机、素材条件判断，而非见到“MV”就增加特效。用户明确指定“写实、克制、极致炫技”等风格时覆盖场景默认偏好，但不能覆盖真实性与连续性硬约束。

可同时命中多场景：例如“纪录片中 20 秒音乐蒙太奇”=人物纪录片真实性硬约束 + 音乐节奏剪辑策略。
